# Question

Match each protocol to the port it listens on by default.

## Draggables

- HTTP
- HTTPS
- SSH
- DNS

## Dropzones

- 80
- 443
- 22
- 53

## Pairs

- HTTP -> 80
> Unencrypted web traffic uses port 80.
- HTTPS -> 443
> TLS-wrapped web traffic uses port 443.
- SSH -> 22
- DNS -> 53
