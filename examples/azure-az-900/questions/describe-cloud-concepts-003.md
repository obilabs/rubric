# Question

A startup company is evaluating cloud services and is particularly interested in a financial model where they pay only for the computing resources they use, without any upfront hardware purchase costs. Which financial model does this describe?

## Choices

A. Capital Expenditure (CapEx)
> Capital Expenditure involves upfront spending on physical assets, which is the opposite of the scenario described.
B. Operational Expenditure (OpEx) *[CORRECT]*
> Operational Expenditure accurately describes a pay-as-you-go model with no upfront capital investment, which is typical for cloud services.
C. Fixed Expenditure
> This term is not a standard financial model for cloud services and implies static, non-variable costs.
D. Depreciation
> Depreciation is an accounting method for allocating the cost of a tangible asset over its useful life, not a purchasing model for services.
