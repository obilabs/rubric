# Question

Match each Azure compute service to its primary characteristic or use case.

## Draggables

- Infrastructure as a Service (IaaS) for full operating system control
- Platform as a Service (PaaS) for hosting web applications and APIs
- Serverless, event-driven compute without managing underlying servers

## Dropzones

- Azure Virtual Machines
- Azure App Service
- Azure Functions

## Pairs

- Infrastructure as a Service (IaaS) for full operating system control -> Azure Virtual Machines
> Azure Virtual Machines offer IaaS, giving users complete control over the operating system, including custom software installation and configuration.
- Platform as a Service (PaaS) for hosting web applications and APIs -> Azure App Service
> Azure App Service is a PaaS offering designed for building, deploying, and scaling web apps, mobile backends, and RESTful APIs without managing infrastructure.
- Serverless, event-driven compute without managing underlying servers -> Azure Functions
> Azure Functions is a serverless compute service that allows you to run small pieces of code (functions) in response to events without provisioning or managing infrastructure.
