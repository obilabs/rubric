# Question

Match each Azure service to its primary characteristic or use case.

## Draggables

- Unstructured object storage for large amounts of data
- Fully managed relational database as a service
- Logically isolated network in Azure for resources

## Dropzones

- Azure Blob Storage
- Azure SQL Database
- Azure Virtual Network

## Pairs

- Unstructured object storage for large amounts of data -> Azure Blob Storage
> Azure Blob Storage is optimized for storing massive amounts of unstructured data, such as text or binary data, and is often used for images, documents, and backups.
- Fully managed relational database as a service -> Azure SQL Database
> Azure SQL Database is an intelligent, scalable, relational database service built on the Microsoft SQL Server engine, offered as a fully managed PaaS.
- Logically isolated network in Azure for resources -> Azure Virtual Network
> Azure Virtual Network (VNet) enables Azure resources to securely communicate with each other, the internet, and on-premises networks in a logically isolated environment.
