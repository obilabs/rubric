# Question

A company wants to deploy a new web application and manage the application code and data, but wants to avoid managing the underlying operating systems, virtual machines, and network infrastructure.

Which cloud service model best meets these requirements?

## Choices

A. Infrastructure as a Service (IaaS)
> This option is incorrect because IaaS requires the customer to manage the operating systems and virtual machines.
B. Platform as a Service (PaaS) *[CORRECT]*
> PaaS provides a managed platform where developers can deploy and manage their applications without needing to manage the underlying infrastructure like operating systems or virtual machines.
C. Software as a Service (SaaS)
> This option is incorrect because SaaS typically involves using a complete, ready-to-use application, with no management of application code or data by the customer.
D. Function as a Service (FaaS)
> This option is incorrect because FaaS is a specific type of serverless computing, which is a subset of PaaS, but PaaS is the broader and more accurate service model for managing application code and data while abstracting OS/VMs.
