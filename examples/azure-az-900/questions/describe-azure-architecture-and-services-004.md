# Question

Match each core Azure service to the type of workload or resource it is designed for.

## Draggables

- Storing unstructured data like images, videos, and backup files
- Providing a fully managed relational database in the cloud
- Creating a private and isolated network for Azure resources

## Dropzones

- Azure Blob Storage
- Azure SQL Database
- Azure Virtual Network

## Pairs

- Storing unstructured data like images, videos, and backup files -> Azure Blob Storage
> Azure Blob Storage is optimized for storing massive amounts of unstructured object data, such as text or binary data.
- Providing a fully managed relational database in the cloud -> Azure SQL Database
> Azure SQL Database is a fully managed platform as a service (PaaS) database engine that handles most of the database management functions such as upgrading, patching, backups, and monitoring.
- Creating a private and isolated network for Azure resources -> Azure Virtual Network
> Azure Virtual Network (VNet) is the fundamental building block for your private network in Azure, enabling many types of Azure resources to securely communicate with each other, the internet, and on-premises networks.
