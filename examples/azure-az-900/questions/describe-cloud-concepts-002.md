# Question

In the shared responsibility model for cloud computing, which of the following is typically the customer's responsibility when using a Platform as a Service (PaaS) offering?

## Choices

A. Physical network
> The physical network is managed by the cloud provider in all cloud service models, including PaaS.
B. Operating system patching
> Operating system patching is typically managed by the cloud provider in a PaaS offering.
C. Application configuration *[CORRECT]*
> In PaaS, the customer is responsible for configuring and managing the applications they deploy onto the platform.
D. Virtualization layer
> The virtualization layer is managed by the cloud provider in PaaS, abstracting it from the customer.
