# Question

A company wants to host its applications in a cloud environment where the computing resources are owned and operated by a third-party cloud service provider and shared among multiple tenants. Which cloud model best describes this scenario?

## Choices

A. Private cloud
> This describes resources dedicated to a single organization, not shared among multiple tenants.
B. Hybrid cloud
> This describes a combination of public and private cloud environments, not solely a shared third-party model.
C. Public cloud *[CORRECT]*
> This accurately describes the characteristics of a public cloud model, where resources are shared and managed by a third-party provider.
D. On-premises
> This describes resources hosted within the company's own data center, not a cloud model provided by a third-party.
