  ΔH_reaction = Σ(Bond energies of bonds broken) - Σ(Bond energies of bonds formed)
  Bonds broken: 4(C-H) + 1(Cl-Cl) = 4(413 kJ/mol) + 1(242 kJ/mol) = 1652 + 242 = 1894 kJ/mol
  Bonds formed: 3(C-H) + 1(C-Cl) + 1(H-Cl) = 3(413 kJ/mol) + 1(339 kJ/mol) + 1(431 kJ/mol) = 1239 + 339 + 431 = 2009 kJ/mol
  ΔH_reaction = 1894 kJ/mol - 2009 kJ/mol = -115 kJ/mol.

# Question
Calculate the enthalpy change (ΔH) for the reaction:
CH₄(g) + Cl₂(g) → CH₃Cl(g) + HCl(g)
Given the following average bond energies:
C-H = 413 kJ/mol
Cl-Cl = 242 kJ/mol
C-Cl = 339 kJ/mol
H-Cl = 431 kJ/mol
## Choices
A. +115 kJ/mol
B. -255 kJ/mol
C. +255 kJ/mol
D. -115 kJ/mol *[CORRECT]*
