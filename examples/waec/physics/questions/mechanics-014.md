  First, calculate the Mechanical Advantage (MA) of the machine: MA = Load / Effort.
  MA = 600 N / 200 N = 3.
  The efficiency (η) of a machine is given by the formula: η = (Mechanical Advantage / Velocity Ratio) * 100%.
  η = (3 / 4) * 100% = 0.75 * 100% = 75%.
