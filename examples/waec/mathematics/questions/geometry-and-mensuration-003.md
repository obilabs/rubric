  Using Pythagoras' theorem for a right-angled triangle, a² + b² = c², where c is the hypotenuse.
  Given a = 5 cm and b = 12 cm.
  c² = 5² + 12² = 25 + 144 = 169.
  Therefore, c = √169 = 13 cm.
