  Since time (T) is inversely proportional to the number of workers (N), $T = \frac{k}{N}$. Using the initial data, $60 = \frac{k}{10}$, so $k = 600$. For 15 workers, $T = \frac{600}{15} = 40$ days.

# Question
The time (T) it takes to complete a road construction project is inversely proportional to the number of workers (N) on the project. If 10 workers complete a project in 60 days, how many days will it take 15 workers to complete the same project?
## Choices
A. 90 days
B. 75 days
C. 45 days
D. 40 days *[CORRECT]*
