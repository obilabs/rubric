  To find the mean, multiply each number of children (x) by its corresponding number of families (f) to get fx. Sum these products (Σfx) and sum the frequencies (Σf). The mean is then Σfx / Σf. Here, Σfx = (0*2)+(1*5)+(2*8)+(3*3)+(4*2) = 0+5+16+9+8 = 38. Σf = 2+5+8+3+2 = 20. So, Mean = 38/20 = 1.9.

# Question
The table below shows the number of children per family in a small community in Calabar:

| Number of children (x) | Number of families (f) |
|---|---|
| 0 | 2 |
| 1 | 5 |
| 2 | 8 |
| 3 | 3 |
| 4 | 2 |

Calculate the mean number of children per family.
## Choices
A. 1.5
B. 1.8
C. 2.0
D. 1.9 *[CORRECT]*
